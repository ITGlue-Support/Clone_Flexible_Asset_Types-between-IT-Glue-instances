# Clone_Flexible_Asset_Types-between-IT-Glue-instances
This PowerShell script copies Flexible Asset Types (FATs) from one IT Glue account to another, including their field definitions. It creates missing templates, copies selected field definitions, skips matching names, and reports the outcome.

Please ensure that the base URL is pointing to the region where your IT Glue accounts are hosted
You will need to supply the API key from the source IT Glue account and the API key for the target IT Glue account
